Términos y Condiciones de Uso

Última actualización: 7 de febrero de 2026

1. Aceptación de los Términos

Al acceder y utilizar Control de Taxi ("la Aplicación"), aceptas estar sujeto a estos Términos y Condiciones. Si no estás de acuerdo, no utilices la Aplicación.

2. Descripción del Servicio

Control de Taxi es una aplicación web progresiva (PWA) que permite:

  • Gestión de servicios de taxi
  • Control de gastos e ingresos
  • Administración de flotas (para patrones)
  • Generación de reportes y estadísticas
  • Funcionamiento offline

3. Registro y Cuenta de Usuario

Para utilizar la Aplicación, debes:

  • Ser mayor de 18 años
  • Proporcionar información veraz y actualizada
  • Mantener la confidencialidad de tu contraseña
  • Notificar inmediatamente cualquier uso no autorizado

Eres responsable de todas las actividades realizadas bajo tu cuenta.

4. Roles de Usuario

👔 Patrón

Gestiona una flota de taxistas, genera códigos de invitación, supervisa servicios y aprueba solicitudes de asociación.

🚗 Taxista

Registra servicios, gestiona gastos, puede asociarse a un patrón mediante código de invitación.

5. Uso Aceptable

Te comprometes a NO:

  • Utilizar la Aplicación para fines ilegales
  • Intentar acceder a cuentas de otros usuarios
  • Introducir virus o código malicioso
  • Realizar ingeniería inversa de la Aplicación
  • Usar la Aplicación para spam o actividades fraudulentas
  • Compartir información falsa o engañosa

6. Almacenamiento Local

⚠️ Importante: Todos los datos se almacenan localmente en tu navegador. No somos responsables de la pérdida de datos por:

  • Borrado de datos del navegador

Recomendación: Exporta regularmente tus datos desde la configuración de privacidad.
